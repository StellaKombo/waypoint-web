    Captures include bounded visible structure and computed design tokens. Input values, cookies, asset URLs and source code are excluded. Visible names may still contain private content; review before export. Evidence stays in memory until you export it.

    Capture or import interface evidence, then create a build brief. No REA runtime is required.

    LOCAL MCP CONNECTOR
    1. Download the agent kit
      The kit contains a local Node.js MCP server and configuration instructions. It runs on your development computer.
      Download agent connector ↓
    2. Add it to your agent’s MCP configuration
      Choose an AI coding tool or desktop assistant that supports launching a local MCP server over stdio. Use the command and absolute server path in the included instructions. A hosted mobile chat cannot automatically reach your local browser.
      Open agent setup instructions ↗
    3. Pair and authorize
      Start the connector through your AI host. Copy its temporary pairing token into the Waypoint extension popup. Select the app tab and choose the allowed capabilities. You can unpair the agent or end the session from the extension at any time.
    4. Describe the outcome
      Tell your agent what to test. It can inspect the page, capture screenshots with your consent, run safe interactions, assert visible text, and produce real audit reports.
      Copy this request into your connected AI tool. This workspace does not send it to a model or claim an AI run has started.
